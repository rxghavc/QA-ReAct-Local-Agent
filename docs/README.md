# Documentation

This folder is organized by purpose so the project is easier to navigate without mixing operational guidance, measured findings, and the historical milestone record into one flat list.

## Documentation map

- [Architecture & infrastructure](architecture/README.md): how the agent, browser, and local model stack fit together, plus the serving and observability constraints.
- [Guides](guides/README.md): the day-to-day instructions for running the agent, working with the benchmark suite, and checking regressions.
- [Research & optimization](research/README.md): planning notes, experiments, and the measured optimization work that shaped the project.
- [Analysis](analysis/README.md): the supporting notes, findings, and lessons that explain the milestone decisions and the project’s tradeoffs.
- [Milestones](milestones/README.md): the numbered project history and the timeline of major experiments, failures, and conclusions.

## Recommended reading order

1. Start with [guides/README.md](guides/README.md) if you want to run the project locally.
2. Read [architecture/README.md](architecture/README.md) to understand the runtime model and the system constraints.
3. Use [research/README.md](research/README.md) for the optimization work and measured reasoning behind the design choices.
4. Visit [milestones/README.md](milestones/README.md) for the authoritative milestone history.

## A note on scope

The milestone documents are intentionally historical records: they capture what was tried, what failed, and what was learned. They are not the primary front door for day-to-day usage.
